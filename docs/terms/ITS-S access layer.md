# ITS-S access layer

communications layer in the [ITS station reference architecture](ITS-S reference architecture.md) comprised of the physical and data link layers of the OSI model

History note: 2026: Revised "corresponding to" to "comprised of" to clarify the relationship type; removed "for ITS communications" as it is implied by the context and only caused confusion at the end of the statement.

History note: 2025: Revised based on input from WG 16 and to align more closely with the other definitions within ISO 14812.

History note: 2022: Added to ISO/TS 14812:2022.

History note: 2014: Introduced in ISO 21217:2014 as "protocol layer in the ITS-S reference architecture containing the OSI physical and data link layer protocols for ITS communications".
